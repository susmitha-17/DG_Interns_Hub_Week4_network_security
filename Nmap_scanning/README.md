# Nmap Scanning

This folder contains the screenshots, scan results, and supporting evidence generated during the Nmap network scanning and reconnaissance phase of the Week 4 Cybersecurity Internship project.

The scanning activities were performed within an authorized virtual lab environment consisting of a Kali Linux attacker machine and an Ubuntu Linux target machine connected through a VirtualBox Host-Only network.

## Objectives

- Perform basic network and port scanning using Nmap.
- Identify open TCP ports on the target system.
- Detect services running on discovered ports.
- Perform service and version detection using Nmap.
- Save and document scan results for further analysis.
- Maintain proper evidence of the security assessment process.

## Lab Configuration

- Scanner: Kali Linux — `192.168.56.102`
- Target: Ubuntu Linux — `192.168.56.101`
- Network: VirtualBox Host-Only — `192.168.56.0/24`
- Tool: Nmap
